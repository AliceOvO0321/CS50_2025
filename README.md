# CS50　受講ノート
## 各回の構成

### Week 0: Scratch
- Scratchによるプログラミング入門
- 論理的思考、制御構造、関数、イベント駆動型設計

### Week 1: C言語の基礎
- Cの文法と構造
- 変数、条件分岐、ループ

### Week 2: 配列とアルゴリズム
- 配列、文字列、文字コード（ASCII）
- 線形探索、バイナリサーチ
- 基本ソート（バブル、選択、挿入）

### Week 3: アルゴリズムとメモリ
- ポインタ、char *、メモリのアドレス
- malloc, free での動的メモリ管理
- 再帰関数

### Week 4: データ構造
- 構造体、リンクリスト、スタック、キュー、ツリー
- 重要: speller 問題準備

### Week 5: ハッシュテーブルと辞書（Trie）
- トライ木の概念と実装
- speller問題：単語のスペルチェックプログラムの開発

### Week 6: Python入門
- Pythonの基本構文（Cとの比較）
- リスト、辞書、ループ、関数
- ファイル操作、モジュールの利用

### Week 7: Python応用
- APIの使い方、エラー処理
- CSV、JSON、データ処理

### Week 8: SQLとデータベース
- データベースの基本、SQLite
- SELECT, INSERT, UPDATE, DELETE
- JOINや正規化（Normalization）

### Week 9: Webプログラミング（Flask）
- FlaskでWebアプリ構築
- HTMLテンプレート、フォーム、セッション管理

### Week 10+: Final Project
- オリジナルプロジェクト開発（CでもPythonでも可）
- GitHubでコード公開、動画でプレゼン
